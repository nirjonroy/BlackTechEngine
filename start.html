BlackTechEngine is an AI-powered SEO automation SaaS inspired by platforms such as Soro, but designed around a stronger feedback loop: Discover → Research → Create → Optimize → Publish → Measure → Improve. Primary goal Build a production-ready SaaS where a user connects a website, the system understands the business, discovers keyword opportunities, generates SEO content, optimizes it, publishes it automatically, syncs Google Search Console data, and recommends/executes improvements. Core product loop Add website Crawl website + sitemap Build brand/business profile Discover and cluster keywords Research SERP/content gaps Build content brief + article SEO optimization + internal linking + images Human review or auto-publish Publish to WordPress/Shopify Sync Search Console/rank data Detect CTR/ranking/content-decay opportunities Refresh/republish content MVP success criteria • Website onboarding works end-to-end • Gemini-powered keyword/content pipeline works • SEO score and editor work • WordPress publishing works • Laravel automation runs without browser interaction • Usage/cost tracking exists • Paddle billing can enforce plan limits • Production monitoring and failed-job recovery exist Development workflow Cards move: Ready → In Progress → Review / QA → Ready to Deploy → Done. Use Blocked only when an external dependency prevents progress. Naming Project: BlackTechEngine Initial positioning: AI SEO Operating System Target users: SMBs, agencies, e-commerce stores, marketers, SEO teams.
